# Pete's Portfolio Starter Project

This repository contains a starter template for Pete's portfolio. The project helps you learn how to create a personal portfolio page using HTML and CSS, while also getting familiar with basic design principles.

## Project Overview

This project takes Pete's original portfolio website and redesigns the look. It makes the About section and Portfolio section more compact for easier viewing as well as the navigation bar.

## Justification for redesign

I utilized flexboxes for all sections. For the navigation, I directly edited into the header. For the about section I created two elements: Pete's profile image and then his about information. Using flex, I aligned them in a row and spaced them evenly. I then created a contatiner for all of his works and used flex to align them horizontally.
